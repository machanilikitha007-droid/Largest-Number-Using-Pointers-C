# Largest Number Using Pointers in C

## Project Description

A simple C program that uses pointers to find the largest number from five numbers entered by the user.

## Features

- Accept five numbers
- Access array elements using pointers
- Find the largest number
- Display the result

## Technologies Used

- C
- Pointers
- Arrays
- Loops

## How to Run

Compile and run the `largest_using_pointer.c` file using a C compiler.
